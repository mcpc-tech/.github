# Welcome to MCPC Tech 🚀

> **One Prompt for Your Agentic MCP Server, Powered by Thousands**

**MCPC** (MCP Compose) revolutionizes agentic automation workflows. With just **one prompt**, instantly create scalable MCP servers powered by thousands of community MCPs.

## 🔗 Key Projects

### 🎯 [mcpc](https://github.com/mcpc-tech/mcpc)
**Core Framework** - The main MCPC repository with SDK, documentation, and examples

### 👷 [cmcp](https://github.com/mcpc-tech/cmcp)
**A experimental MCP client that supports client tool calls**

### 🔧 [oapi-invoker-mcp](https://github.com/mcpc-tech/oapi-invoker-mcp)
**OpenAPI Integration** - MCP server for invoking OpenAPI/REST services

### ⚡ [code-runner-mcp](https://github.com/mcpc-tech/code-runner-mcp)
**Code Execution** - Safe code execution environment for automation workflows

## 🚀 Quick Start

1. **Web Interface**: Visit [mcpc.tech](https://mcpc.tech/) for instant workflow creation
2. **Developer SDK**: `npx jsr add @mcpc/core` for programmatic access
